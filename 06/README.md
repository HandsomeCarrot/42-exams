### keywords

- exercise -> self-explanatory

- **status**
	- passed -> I passed this exercise in the exam

		> (up-to-date) -> implementation in this repo is essentially the same as I had it in the exam

	- failed -> I failed this exercise in the exam

		> (updated) -> I think I have implemented a passable implementation of the exercise, afterward

	- confirmed -> A peer, on my campus, got this exercise

		> the subject and the given files, where not confirmed by the peer

	- unconfirmed -> I found this exercise online

		> all information (i.e. subject, given files, exam level) about this are unconfirmed

- **points** -> how many percentage points the exercise gives

- **impl.**
	- yes -> implemented in some form on this repo
	- wip -> started implementation / broken
	- no -> not implemented
